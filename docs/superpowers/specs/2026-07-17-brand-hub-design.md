# 品牌中心与首页命名调整设计

## 目标

将应用的信息架构调整为“首页 / 品牌 / 我的”，把原先独立的品牌专项练习与题库管理整合到以品牌为中心的单一流程中，同时统一学习与错题记录的文案。

## 页面与导航

- 底部导航的“练习”改为“首页”，“专项”改为“品牌”。
- 首页保留随机练习、每日目标与原有快捷功能；其中“品牌专项”快捷卡改为“学习记录”，跳转到既有学习历史页面。
- “错题本”在设置入口、列表页、详情页返回提示等用户可见位置统一改为“错题记录”。
- 删除“题库管理”的独立设置入口与独立列表页入口。

## 品牌中心

品牌页面继续使用现有的分类、搜索和品牌卡片。页面保留新增自定义品牌入口。

点击任一品牌后进入品牌详情。详情页顶部展示品牌 logo、中文/英文名称、车型数量和醒目的“开始练习”按钮。按钮以该品牌 ID 创建既有的 `QuizMode.BrandPractice`，题目范围为该品牌的全部车型。

详情页下方展示该品牌全部车型，采用清晰的卡片或列表排版。详情页同时承接题库维护：可新增、编辑、删除自定义车型；自定义品牌可编辑或删除。内置品牌与车型仍沿用现有的只读约束，避免修改内置题库数据。

## 数据流与兼容性

- Room 数据结构、仓库方法和练习生成逻辑保持不变。
- 品牌详情直接使用已加载的 `Brand.cars` 数据渲染车型，并复用现有的品牌/车型编辑对话框和仓库写入方法。
- 写入完成后重新加载品牌列表，使车型数量、车型列表和练习题目立即反映最新数据。
- 未找到品牌或无车型时继续使用应用现有的空状态提示与返回路径。

## 验证

- 为导航和首页快捷入口的文案/路由增加或更新单元测试。
- 为品牌详情的展示模型或页面常量增加测试，覆盖车型数量、练习入口和题库维护能力。
- 运行完整单元测试与 debug 构建，确认编译和既有行为未回归。
