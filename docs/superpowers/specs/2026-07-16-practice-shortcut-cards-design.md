# 练习首页快捷卡设计

## 目标

将练习首页底部单调的“品牌专项”和“错题复盘”快捷卡，改为与其功能和当前本地数据相对应的双入口卡，同时保持现有页面跳转和深蓝科技风。

## 已确认需求

- 品牌专项卡显示“品牌专项”和“按品牌练习”，并叠放最多三个项目已注册的真实品牌 Logo。
- 错题复盘卡显示本地待复盘错题数量；有错题时突出“待复盘 X 道”，没有错题时显示“暂无错题 · 继续保持”。
- 错题卡使用粉红警示色、叠层错题标签和右下箭头；品牌卡使用白底 Logo 瓷砖、蓝色光效和右下箭头。
- 两张卡保持并只保持现有点击行为：品牌专项进入品牌选择页，错题复盘进入只读错题本。
- 不使用效果图中的虚构 Logo 或将生成图片写入项目；直接复用 `BrandLogoRegistry` 和已有 drawable。
- 不新增数据库字段、Room 迁移、依赖、练习/重试按钮或版本变更。

## 数据与架构

新增小型纯展示模型 `MistakeReviewShortcutPresentation`，将非负的待复盘数量转为有错题和零错题两种文案及状态。该模型使用 JVM 单元测试覆盖，避免 UI 直接散落零值判断。

`MainShell` 在进入“练习”页时读取今日完成题数和 `repository.mistakes().size`，把错题展示模型传给 `RandomPracticePage`。品牌卡从已经加载的 `brands` 中筛选已注册 drawable 的品牌，最多展示三个；没有可用 Logo 时显示稳定的文字后备内容。

## 视觉与交互

两张卡保持一行双列和当前圆角、边框、深蓝渐变。品牌卡由标题、说明和重叠的白底 Logo 瓷砖组成；错题卡由标题、状态文案、叠层的小型复盘标签和圆形警示符号组成。卡片右下方都有蓝色箭头，作为进入入口的视觉提示。所有元素可在窄屏双列中显示，不横向滚动。

## 验收标准

- 待复盘数为 2 时，错题卡文案为“待复盘 2 道”；数量为 0 时，文案为“暂无错题”和“继续保持”。
- 品牌卡最多显示三个 `BrandLogoRegistry` 可解析的真实品牌 Logo，缺少 Logo 时无崩溃且有文字后备。
- 进入练习首页后，错题数来自本地 `repository.mistakes()`；两张卡点击仍分别进入 `special` 和 `mistakes`。
- 不显示“重新练习”或新操作按钮。
- `testDebugUnitTest assembleDebug` 成功。
