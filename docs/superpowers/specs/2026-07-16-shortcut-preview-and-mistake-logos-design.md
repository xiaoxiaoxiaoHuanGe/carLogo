# 快捷卡预览对齐与错题品牌 Logo 设计

## 目标

让练习首页的“品牌专项”和“错题复盘”严格采用已确认预览的共同卡片骨架，并让错题本每条记录左侧显示对应品牌车标而非红色感叹号。

## 已确认需求

- 两张首页快捷卡标题必须在同一高度、同一基线；不能让错题卡的警示徽章影响标题布局。
- 双卡保持一行双列、相同 180dp 高度、深蓝 TechCard 轮廓和底部右侧蓝色 `→`。
- 品牌卡按预览显示：标题“品牌专项”、副标题“按品牌练习”、底部中央三张重叠的真实品牌 Logo 瓷砖。
- 错题卡按预览显示：标题“错题复盘”、真实“待复盘 X 道”状态、说明文字、叠层复盘标签及右侧粉红警示圆徽；零错题使用成功色的 `✓` 状态。
- 错题本列表每条卡片左侧使用对应 `brandId` 的品牌车标。对没有注册 drawable 的自定义品牌保留一个稳定、非错误态的文字后备图标，不能崩溃。
- 不新增图片资源、数据库字段、迁移、路由、练习/重试按钮、依赖或版本变更。

## 架构

`MistakePresentation` 增加 `brandId`，由 `MistakePresentationMapper` 在已解析品牌时写入。模型单元测试验证两个题型都保留正确品牌 ID。`MistakesScreen` 使用已有 `brands` 和 `BrandLogoTile` 解析并显示品牌 Logo，不能解析时显示品牌首字/“车”的中性后备图标。

首页快捷卡在 `App.kt` 中共享固定高度的标题槽（同一高度和标题样式）；各自独立将 Logo 叠层或复盘队列放进标题槽之下。警示圆徽改为绝对定位于错题卡右上，不参与标题的 `Row` 测量，确保基线对齐。

## 验收标准

- 两张卡的标题使用同一标题槽和同一文本样式；警示徽章不改变错题卡标题的起始位置或基线。
- 品牌卡居中显示最多三张重叠的、已注册真实品牌 Logo；错题卡的待复盘数来自既有展示模型。
- `MistakePresentationMapper` 对“看车型猜品牌”和“看品牌选车型”都输出原始品牌 ID。
- 凯迪拉克等已注册品牌的错题卡左侧渲染车标，而非 `!`；无注册 Logo 的品牌显示后备图标。
