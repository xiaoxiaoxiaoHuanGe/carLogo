# GitHub README 设计说明

## 目标

为“猜车品牌”Android 应用提供一份面向 GitHub 访问者的中文首页说明，使使用者能快速了解用途、功能和 APK 安装入口。

## 内容范围

README 将以中文完整说明以下内容：

- **应用定位**：一款离线运行的汽车品牌记忆练习 App，帮助用户通过选择题熟悉“车型属于哪个品牌”以及“品牌有哪些车型”。
- **练习方式**：随机练习固定为 20 题；题型均衡覆盖“车型识别”和“品牌识别”。
- **答题体验**：单题四选一、即时对错反馈、得分/正确率/进度展示、答对后的过渡动画，以及已答题范围内的上一题、下一题和左右滑动回顾。
- **专项与复盘**：可按品牌分类筛选进行专项练习；错题会保存在本机，并能在错题复盘入口中再次练习。
- **题库能力**：内置常见燃油车、新能源、豪华、合资和国产自主品牌；品牌支持分类下拉选择，车型可以保留中英文名称；用户还可以新增或编辑自定义品牌和车型。
- **数据与隐私**：题库、答题进度和错题记录均存储在手机本地，不依赖后端账号或网络服务。
- **技术信息**：原生 Android 应用，使用 Kotlin、Jetpack Compose 和 Room 数据库开发。
- **安装与使用**：说明如何从 GitHub Releases 下载 APK、允许安装未知来源应用并完成安装。
- **开发构建**：说明使用 Gradle 生成调试版 APK 和签名发布版 APK 的命令。

## 发布约定

不将构建产物提交到 Git 仓库；可安装的 APK 仅作为 GitHub Release 附件发布。
